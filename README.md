[![Quality Gate Status](https://sonarcloud.io/api/project_badges/measure?project=N-Davie_python-project-49&metric=alert_status)](https://sonarcloud.io/summary/new_code?id=N-Davie_python-project-49)


This program is designed for math games with the user. Each sub-game consists of 3 rounds, where you must enter the correct answers to win. If you fail, you’ll see the correct answer and start over. To run the game, you need to clone the repository and install the dependencies. The games are launched using the following commands: brain-calc, brain-even, brain-games, brain-gcd, brain-prime, brain-progression.
